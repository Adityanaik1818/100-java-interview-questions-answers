## 🎯 About This Repository

This repository is a **Java interview preparation resource** containing **100 Java questions and answers** organized into major Java development topics.

It starts with fundamental Java concepts and gradually moves through advanced frameworks:

> **Java Fundamentals** ➔ **OOP** ➔ **Exception Handling** ➔ **Collections** ➔ **Multithreading** ➔ **File I/O & Serialization** ➔ **JDBC** ➔ **Networking** ➔ **Advanced Java** ➔ **Spring Framework**

**💡 Goal:** Understand the concept, practice it with code, and then explain it confidently during an interview.
